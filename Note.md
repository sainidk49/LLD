# OOPs

OOPS stands for Object Oriented Programming System. It is a programming paradigm that organizes code using classes and objects. The main goal of OOPS is code reusability, maintainability, scalability and security. OOPS is based on four pillars: Encapsulation, Inheritance, Polymorphism and Abstraction.

1. Encapsulation helps protect data by restricting direct access. 
2. Inheritance allows one class to acquire properties and methods of another class. 
3. Polymorphism allows the same method to behave differently in different classes. 
4. Abstraction hides complex implementation details and exposes only required functionalities to the user.
